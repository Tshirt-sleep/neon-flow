# NEON FLOW

A neon particle-dodge game built with HTML Canvas, CSS, and vanilla JavaScript.

## Play

Open `index.html` in a modern browser. Move with the mouse or touch, or use WASD / arrow keys. Click the sound toggle to mute or enable synthesized audio.

## GitHub Pages

This project is a single static HTML file. In the repository settings, enable GitHub Pages from the `main` branch and the root folder to publish it.
